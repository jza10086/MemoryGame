# 方向密码

使用 Godot 4.7 打开 `project.godot`，按 F5 开始游戏。

## 玩法

- 共六轮，每轮重新随机生成上、右、下、左的序列，长度依次为 3～8。
- 准备倒计时两秒，然后逐个显示方向；相邻方向之间有空白间隔，包括连续相同方向。
- 展示结束后输入答案。每轮作答时间为 `方向数量 × 3 + 4` 秒。
- 方向键、WASD 或屏幕按钮输入；Backspace 撤销；填满后 Enter 或按钮提交。
- 超时自动结算，未填写位置算错；提交前不揭示对错。
- 每个正确位置 100 分，全对额外 100 分，不按速度加分。六轮满分 3900。
- 结算逐格展示正误与正确密码；最后显示每轮得分和总正确率。
- 「重新开始」随时回到起始页；最终「再玩一次」开始新的一局。

场景根节点的 `arrow_seconds` 与 `gap_seconds` 可调整展示和间隔时间。
