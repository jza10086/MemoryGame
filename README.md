# 方向密码：单人原型

在 GodotParty 主工程打开 `res://games/minigame/direction_password/direction_password.tscn`，按 **F6** 启动。
大厅选择「小游戏轮换 → 方向密码」可以启动单人局。六轮结束后按实际得分和正确率进入公共结算，再返回轮换。

## 玩法

- 共六轮，每轮重新随机生成上、右、下、左的序列，长度依次为 3～8。
- 准备倒计时两秒，然后逐个显示方向；相邻方向之间有空白间隔，包括连续相同方向。
- 展示结束后输入答案。每轮作答时间为 `方向数量 × 3 + 4` 秒。
- 方向键、WASD 或屏幕按钮输入；Backspace 撤销；填满后 Enter 或按钮提交。
- 超时自动结算，未填写位置算错；提交前不揭示对错。
- 每个正确位置 100 分，全对额外 100 分，不按速度加分。六轮满分 3900。
- 结算逐格展示正误与正确密码；最后显示每轮得分和总正确率。
- 「重新开始」随时回到起始页；最终「再玩一次」开始新的一局。

场景根节点的 `arrow_seconds` 与 `gap_seconds` 可调整展示和间隔时间。
[Noto CJK 中文字体](https://github.com/notofonts/noto-cjk)与[许可](assets/fonts/FONT-LICENSE.txt)随包提供。

## 回归检查

旧自动测试已退役归档；后续定向检查只放在项目根目录 tmp/test/。
覆盖逐位置评分、重复方向间隔、观察阶段输入锁、键盘重复过滤、撤销、超时、重复结算保护、重开、六轮结算与不同分辨率布局。
程序化检查不代替真实键鼠操作和记忆难度体验。

## 正式单人接入（G02）

正式场景由协议 SoloRound 显式注入 PartyInput 与翻译，准备阶段不启动模拟；确认开始后才接受操作，结算/取消时显式停止。正式 Esc 打开框架菜单，键盘与按钮遵守同一输入屏蔽；菜单本身不暂停计时。包内 `settings.gd` 声明可改键动作，F6 使用同一默认绑定且不增删全局 InputMap。观战端不运行本机模拟。
